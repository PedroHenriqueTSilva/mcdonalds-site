# McDonald's — Fome de coisa boa

Landing page responsiva de portfólio inspirada no McDonald's, com HTML, CSS e JavaScript puro. Projeto independente do site Coca-Cola na pasta vizinha.

## Funcionalidades

- Menu móvel acessível, com fechamento por Escape.
- Cardápio com filtros de sanduíches, acompanhamentos e sobremesas.
- Janelas de detalhes com navegação por teclado e restauração do foco.
- Layout adaptado a celular, tablet e desktop.
- Respeito à preferência por movimento reduzido.
- Imagens locais, sem dependência do servidor da marca durante a navegação.

## Abrir e editar

Abra `index.html` no navegador. Não é necessário instalar dependências.

- `index.html`: conteúdo e estrutura.
- `styles.css`: aparência e adaptações responsivas; cores em `:root`.
- `script.js`: menu, filtros e detalhes dos produtos.
- `assets/`: imagens.

As fontes Barlow Condensed e DM Sans são carregadas pelo Google Fonts e exigem conexão à internet. Fontes alternativas são usadas quando o serviço está indisponível.

## GitHub Pages

Envie o conteúdo desta pasta para a raiz de um novo repositório. Em **Settings → Pages**, selecione **Deploy from a branch**, branch **main**, pasta **/ (root)** e salve. Os arquivos usam caminhos relativos, compatíveis com repositórios de projeto no GitHub Pages.

Projeto conceitual de portfólio, sem vínculo com o McDonald's. Não recebe pedidos nem pagamentos. McDonald's, Big Mac, McFritas e imagens de produtos pertencem aos respectivos titulares; esses materiais não são oferecidos sob licença livre por este projeto.
